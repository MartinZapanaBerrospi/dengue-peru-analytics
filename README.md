# Dengue Perú Analytics

> **En construcción.** El proyecto avanza por fases; este README se completa con los hallazgos y
> el enlace al tablero al terminar.

Análisis de la **vigilancia epidemiológica del dengue en el Perú**: 1,03 millones de casos entre 2000 y
2024 del CDC Perú, con **datos abiertos reales** del Ministerio de Salud: cuándo golpean las epidemias,
dónde se concentran por habitante, a quién afectan y qué tan graves son. Termina en un tablero de
Power BI para gerencia.
